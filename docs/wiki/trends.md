# 유튜브 동향

> 핵심: 영상을 만들기 전에 꼭 읽는 페이지. 지금은 유튜브 공식 리포트와 사용자가 직접 보고 느낀 것만 모은다. 유튜브 감사가 승인되면 데이터 분석을 더한다.

## 어떻게 쌓나
- 유튜브 공식 트렌드 리포트, 기사 링크를 Claude에게 주면 날짜·출처를 붙여 여기에 정리한다.
- 매주 텔레그램으로 오는 인기 차트를 보고 눈에 띈 점(주제, 길이, 제목, 썸네일 느낌)을 말해 주면 "사용자 관찰"로 기록한다.
- 내 채널이 생기면 내 영상 성과도 여기에 더한다.
