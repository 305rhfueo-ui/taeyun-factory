# 유튜브 정책

> 핵심: 유튜브 API 감사 승인 전에는 여러 채널의 데이터를 모으거나 조회수로 지표를 만들지 않는다. 트렌드는 공식 리포트·관찰 메모·내 채널 데이터로 배운다.

[YouTube API 개발자 정책](https://developers.google.com/youtube/terms/developer-policies) (2026-10-29 확인)
- III.E.2 — 같은 소유자의 채널끼리만 데이터를 합칠 수 있다. 유튜브 이용 동향을 알아내려고 모으는 것은 안 된다.
- III.E.4.h — API 데이터로 새 지표·파생 데이터를 만들지 않는다.
- III.L — 파생 지표와 통계 보관은 감사를 받고 "Analytics & Reporting" 용도로 신청해 허가받은 개발자만. 허가되면 통계·파생 지표는 최대 36개월, 제목·채널명·댓글 원문은 여전히 30일 ([파생 지표 정책](https://developers.google.com/youtube/terms/derived-metrics-policy)).
- AI 학습에 써도 되는지는 정책에 언급이 없다 → 감사 신청서에서 직접 묻는다.

## 지금 하는 것
- 매주 유튜브 인기 차트(유튜브가 매긴 순위 그대로) 제목·링크만 텔레그램으로. 저장·사이트 게시 없음.
- 사용자가 준 유튜브 공식 트렌드 리포트(Culture & Trends)·기사·관찰 메모를 위키에 정리.
- 내 채널이 생기면 YouTube Analytics(같은 소유자라 허용)로 내 영상 성과를 배운다.

## 하지 않는 것
- 남의 영상 내려받기, 화면 긁어오기 (승인과 관계없이 금지 — III.E.1·III.E.6)
