# 2026-W44 GitHub 영상 기술 동향

기준일 2026-10-29 · 숫자는 GitHub API 값, 해석은 기술 정찰병(Claude)

## 핵심
- 이번 주는 모든 추적 저장소가 첫 기록이라 별 증가(delta)는 아직 비교할 수 없어요. 다음 주부터 비교가 됩니다.
- HyperFrames(v0.8.214)와 laya(v0.4.17), Remotion(v4.0.539)이 모두 10/26~28 사이에 새 버전을 냈어요. 세 도구 다 활발히 업데이트되는 중이에요.
- '에이전트가 영상을 만들어 주는' 저장소가 최근 한 달 새 많이 생겼어요(openfilm, mortiflix-oss, frametell, vvv 등). 우리 공장과 같은 방향의 흐름이에요.
- Remotion 라이선스가 NOASSERTION이고 OpenMontage는 AGPL-3.0이에요. 상업 이용 전에 조건을 확인해야 해요.
- 중국어 중심의 숏폼 영상 스킬(vibe-knowledge-film, wallstreet-explainer 등)이 늘고 있어요. 다만 이건 참고용 패턴이고, 남의 형식을 베끼면 안 돼요.

## 써볼 만한 것
- [actionow-ai/vvv](https://github.com/actionow-ai/vvv) — Remotion 템플릿을 한 번 만들어 여러 에이전트에서 재사용하게 해 주는 도구예요. 우리의 '같은 디자인, 주제만 바꿔 반복' 흐름과 딱 맞아요. 라이선스는 MIT라 상업 이용에 걸림이 없어요. 다만 생긴 지 일주일이고 별이 434개라 아직 이르니, 구조만 참고하는 걸 권해요.
- [openfilm/openfilm](https://github.com/openfilm/openfilm) — 코딩 에이전트를 영상 에이전트로 바꿔 주고, 만든 결과를 편집기에서 고칠 수 있다는 점이 우리 '만들고 손으로 다듬기' 흐름과 비슷해요. MIT 라이선스예요. 별 3,368개로 신규 중 가장 많이 받았지만, 아직 한 달 된 프로젝트라 써 보기 전에 작은 영상 하나로 시험해 보세요.
- [GTKottman/mortiflix-oss](https://github.com/GTKottman/mortiflix-oss) — Claude가 단계마다 영상을 만들고 사람이 단계별로 승인하는 구조라, 우리 '승인1·승인2' 제작 흐름과 닮았어요. 참고할 만해요. 단, 라이선스가 AGPL-3.0이라 코드를 가져다 서비스에 쓰거나 수정해서 배포하면 소스 공개 의무가 생길 수 있어요. 직접 쓰기보다 아이디어만 참고하는 게 안전해요.
