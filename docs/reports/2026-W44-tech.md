# 2026-W44 GitHub 영상 기술 동향

기준일 2026-10-29 · 숫자는 GitHub API 값, 해석은 기술 정찰병(Claude)

## 핵심
- 핵심 3종(Remotion·HyperFrames·OpenMontage)은 모두 활발하다: Remotion v4.0.539, HyperFrames v0.8.214가 이번 주 나왔고, 별은 각각 68,620 / 74,746 / 72,739개다. 이번이 첫 기록이라 별 증가량은 아직 모른다.
- 라이선스 주의: OpenMontage는 AGPL-3.0이다. 내부에서 쓰는 건 괜찮지만 이걸 고쳐서 서비스로 내놓거나 배포하면 소스 공개 의무가 생길 수 있다. Remotion은 라이선스가 'NOASSERTION'으로 표시돼 자동 판독이 안 된다. 상업 이용 조건(회사 규모별 유료 등)을 공식 페이지에서 직접 확인해야 한다.
- 새로 뜬 흐름은 '코딩 에이전트가 영상을 만들게 하는 도구'다: openfilm(별 3,368), manimgx(2,272), motionmaxxing(1,098), vvv(434) 같은 저장소가 한 달 안에 만들어져 빠르게 별을 모으고 있다.
- claude-code-video-toolkit(v0.23.0, MIT)은 별은 2,369개로 적지만 Claude Code용이라 우리 작업 방식과 가장 가깝고 릴리스도 이번 주에 나왔다.
- 한 달 된 저장소는 아직 검증이 안 됐다. 별 숫자만 보고 바로 도입하지 말고, 우리 흐름(승인1→제작→검수→승인2)에 맞는지 작게 시험해 본 뒤 결정하자.

## 써볼 만한 것
- [Tejashmakwana/motionmaxxing](https://github.com/Tejashmakwana/motionmaxxing) — AI가 만든 밋밋한 영상을 모션 디자이너가 만든 느낌으로 다듬는 에이전트 스킬(Apache-2.0, 상업 이용 무난). 우리 품질 기준과 검수 단계에 참고할 만하다. 다만 만들어진 지 한 달이라 아직 이르다. 한 편에 시험 적용해 보고 판단하자.
- [actionow-ai/vvv](https://github.com/actionow-ai/vvv) — 편집 가능한 Remotion 템플릿과 에이전트 스킬을 한 번 만들어 재사용하는 방식(MIT)이다. '같은 디자인을 주제만 바꿔 반복'하는 Remotion 흐름과 정확히 맞는다. 별은 434개로 작아서 아직 이르니, 템플릿 구조 아이디어만 먼저 참고하자.
- [digitalsamba/claude-code-video-toolkit](https://github.com/digitalsamba/claude-code-video-toolkit) — Claude Code로 영상을 만드는 툴킷(MIT, 상업 이용 무난)이고 이번 주 v0.23.0이 나왔다. 우리 환경과 가장 비슷해서 쓸 만한 부분을 골라 볼 가치가 있다. 별이 적어 안정성은 직접 확인이 필요하다.
